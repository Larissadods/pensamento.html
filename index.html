Curiosidades do mundo tecnologico!

Por: Larissadods

  • O primeiro "Bug" de computador foi um inseto de verdade: Em 1947, a renomada cientista da computação Grace Hopper estava trabalhando no computador Mark II na Universidade de Harvard quando a equipe encontrou uma falha. Ao investigarem a máquina, descobriram uma mariposa real presa em um dos relés. O inseto foi removido e colado no diário de bordo com a anotação: "Primeiro caso real de um bug sendo encontrado". Daí surgiu o termo que usamos até hoje para erros de software.

Curiosidades sobre HTML!

Por: Larissadods

  • A origem do HTML: A linguagem foi criada em 1990 pelo físico britânico Tim Berners-Lee no laboratório CERN, na Suíça, com o objetivo inicial de facilitar o compartilhamento de documentos e pesquisas entre cientistas.
  • O HTML começou "invisível": A primeira versão oficial do HTML continha apenas 18 tags básicas. Muitas delas foram criadas para organizar documentos acadêmicos. Curiosamente, a base da internet como conhecemos hoje só se popularizou mundialmente em 1992, quando a biblioteca World Wide Web foi liberada ao público.

Conheça o p5.js!

Por: Larissadods

O p5.js é uma biblioteca gratuita e de código aberto da linguagem JavaScript,
projetada para tornar a programação acessível e visual. Ele facilita a criação de projetos
interativos, arte digital, jogos e visualizações de dados diretamente na web, servindo como
uma ferramenta para iniciantes, artistas e educadores.

O que é JavaScript?

Por: Larissadods

JavaScript é uma linguagem de programação interpretada de alto nível, essencial para criar dinamismo e interatividade na web. Junto com o HTML e CSS, ela forma a base da internet moderna, permitindo desde animações e validação de formulários até o desenvolvimento de sistemas complexos.

O que é Python?

Por: Larissadods

Python é uma linguagem de programação de alto nível, de código aberto e muito fácil de aprender. Criada nos anos 90, ela tem uma sintaxe limpa que lembra o inglês, sendo amplamente usada em inteligência artificial, análise de dados, automação de tarefas e desenvolvimento web.

  • Simplicidade: O código é direto e fácil de ler, o que a torna ideal para iniciantes.
  • Versatilidade: É utilizada para criar desde pequenos scripts de automação até sistemas complexos e sites.
  • Comunidade Ativa: Possui milhares de bibliotecas gratuitas que facilitam a criação de novos programas sem precisar reinventar a roda.

Diferença entre Java e JavaScript!

Por: Larissadods

Java: É compilado e usado principalmente para softwares robustos, servidores (back-end) e aplicativos mobile (Android).

JavaScript: É uma linguagem de script leve, executada diretamente nos navegadores (front-end) para criar páginas web interativas.
